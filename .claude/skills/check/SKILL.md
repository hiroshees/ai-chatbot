# check

CLAUDE.md の作業ルール「実装後は `pnpm lint`、型チェック、`pnpm test` を通してから完了報告する」を実行するためのスキル。

## 手順

1. 次の3つを、この順で実行する（1つ失敗しても残りは実行して全体像を把握する）。
   - `pnpm lint`
   - `pnpm typecheck`
   - `pnpm test`
2. 失敗があれば、原因となるファイルと行を特定し、修正する。修正したら失敗したコマンドだけでなく3つすべてを再実行する。
3. 実APIを叩くコマンド（`pnpm agent:try`、`pnpm load:test`）や `pnpm build` は、ユーザーが求めたときだけ実行する。

## 報告の形式

| コマンド | 結果 |
| --- | --- |
| lint | 成功 / 失敗（件数） |
| typecheck | 成功 / 失敗（件数） |
| test | 成功 / 失敗（通過数/総数） |

- 失敗が残る場合は、出力をそのまま示して「通っていない」と明記する。成功したと言い換えない。
- スキップしたものがあれば、その理由とあわせて書く。
